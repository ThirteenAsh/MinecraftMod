# MinecraftMod

一个 **以原版 Minecraft 为核心的轻量级增强模组（Vanilla+）**  
基于 Fabric Loader 开发，用于个人学习与 Minecraft 模组开发实践。

---

##  模组简介

本模组围绕 **Minecraft 原版玩法** 进行小幅度拓展，遵循“**尽量保持原版风格**”的设计理念。

主要内容包括：

-  对原版合成配方进行增强或补充  
-  在原版体系内加入 **少量新物品**
-  不引入复杂系统，保持原版平衡
-  作为个人 Fabric 模组开发的学习项目

---

##  模组特点

- **Vanilla+ 设计理念**  
  所有内容力求自然融入原版玩法  

- **原版配方增强**  
  - 为部分原版资源提供更多用途  
  - 改善或补充原版合成逻辑  

- **少量新物品**  
  - 新物品服务于原版内容  
  - 不引入科技树或大型系统  

- **学习向模组**  
  - 用于熟悉 Fabric 模组结构  
  - 练习物品、配方、注册流程等基础内容  

---

## 🛠 开发目的

>  **声明**

本模组为 **个人学习用途** 制作：

- 用于学习 Java 与 Fabric 模组开发

---

##  当前内容

- 原版物品配方扩展
- 原版资源更多利用方式
- 简单的新物品与合成配方

---

##  使用说明

1. 安装 **Minecraft 1.20.1**
2. 安装 **Fabric Loader**
3. 安装 **Fabric API**
4. 将本模组放入 `mods` 文件夹
5. 启动游戏即可

---

##  开发环境与依赖

- **Minecraft**：`1.20.1`
- **Fabric Loader**：`>= 0.17.2`
- **Fabric API**：必需
- **Java**：`Java 17 或更高版本`
